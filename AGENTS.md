# Agent instructions

- Read [the product direction](docs/product.md) before changing behavior or scope.
- Follow [the contribution guide](CONTRIBUTING.md) for verification, issues, pull requests, and commit messages.
- Write repository documentation, issues, pull requests, and commit messages in English.
- Keep implementation within the agreed scope. Record the rationale and verification for changes to code generation, diagnostics, or dependencies in the pull request.
- Keep credentials, customer data, and private planning notes out of commits and test fixtures.
